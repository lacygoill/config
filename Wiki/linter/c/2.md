Msg: Only works if the system uses ASCII code.

# Bad:

    char ch = 65;

# Good:

    char ch = 'A';

# Rationale:

Using `'A'` instead of `65` produces  code that works on any system.  Therefore,
it's much better to use character constants than numeric code values.

# Regex:

    ^\s*char\s\+\i\+\s*=\s*\zs\%(\d\+\>\|'\\\%(\d\|x\)\)
